# 毛利率归因口径

这套方法只做**数据归因**：把总毛利率的变化分摊到对象、订单和价格 / 成本两项上，不解释业务原因。

## 1. 毛利率

[
R = 1 - \frac{K}{S}
]

- (S)：销售收入
- (K)：销售成本
- 上期 (R_0)，本期 (R_1)，毛利率变化 ( \Delta R = R_1 - R_0 )。

## 2. 拉力（pull）

某个对象对总毛利率的拉力：

[
pull = \frac{(1 - R_0) \times S - K}{S_{period}}
]

- 上期行除以 **上期总收入 (S_0)**；
- 本期行除以 **本期总收入 (S_1)**；
- 上期逐行拉力合计为 0；本期逐行拉力合计等于 (R_1 - R_0)。

**不要把所有行都除以本期总收入。** 这是 Excel 复算最常见的错误。

## 3. 价格拉力 / 成本拉力

[
price = \frac{(1 - R_0)(S - P_0 \times Q)}{S_{period}}
]

[
cost = \frac{C_0 \times Q - K}{S_{period}}
]

- (P_0 = S_0 / Q_0)：上期加权平均单价；
- (C_0 = K_0 / Q_0)：上期加权平均单位成本；
- (Q)：当期数量；
- 恒等式：(pull = price + cost)。

价格 / 成本两项是**相对上期基准的拉力**，不是价格指数 / 成本指数。结构变化会同时进入两项，所以两项可能很大、方向相反。

## 4. 拉力水平与拉力差值

不要把这两个概念混在一起：

### 4.1 拉力水平（谁撑起本期毛利率）

每个对象在第 t 期有一个拉力水平 (pull_0) / (pull_1)。本期拉力回答“谁把本期毛利率撑在上面 / 拖在下面”：

[
R_1 = R_0 + \sum pull_1
]

- 上期逐行拉力合计为 0；
- 本期逐行拉力合计等于 (R_1 - R_0)；
- 正的本期拉力 = 高于上期总体毛利率，负的本期拉力 = 低于上期总体毛利率；
- 排序用 (pull_1)，不是 (\Delta pull)。

### 4.2 拉力差值（谁导致了变化）

[
\Delta pull = pull_1 - pull_0
]

按客户、产品、地区、渠道等维度汇总后，所有对象的 (\Delta pull) 相加等于 (R_1 - R_0)。订单级同理。

- 拉力水平回答“谁撑起了本期毛利率”；
- 拉力差值回答“谁让毛利率变了”；
- 两者排序可能完全不同：某个对象本期拉力很高，但上期也高，拉力差值可能很小；反过来，某个对象本期仍在拖累，但拖得比上期少，拉力差值可以是正的。

## 5. 结论的帕累托截断

- 主维度：按正向 / 负向分别累计，累计到 80% 或前 7 大，先到先止。
- 订单：每个对象按同向订单累计，累计到 80% 或前 15 张，先到先止。
- 若先触顶（还没到 80%），必须写清楚“覆盖 xx%，未达 80%，已按上限截断”，不能把截断说成达标。
- 数据很散时，列出数十个对象没有阅读价值；上限是阅读兜底，不是统计上更优。

## 6. 二维象限

- X = 单价，单价越高越靠右；
- Y = 单位成本，成本越高越靠上；
- 分割线：上期加权均价 (P_0)、上期加权平均单位成本 (C_0)；
- 屏幕位置：
  - 左上：低单价 / 高成本 = 失血区
  - 右上：高单价 / 高成本 = 附加值区
  - 左下：低单价 / 低成本 = 走量区
  - 右下：高单价 / 低成本 = 暴利区
- 气泡大小 = 所选期间收入；
- 气泡颜色 = 两期拉力差值方向：正绿、负红；
- 零成本 / 零收入可以定位；数量为 0 或负收入 / 负成本才列为未定位。

## 7. 象限浓度

- 象限收入占比 = 象限收入 / 当期总收入；
- 上期、本期分别用各自的总收入做分母；
- 两期迁移比较四象限占比变化；占比变化单位是百分点（pp），不是百分比；
- 路径表显示“上期象限 → 本期象限”的对象数、两期占比和本路径变化；
- 单条路径变化不等于象限净变化，因为同一象限有进有出。

## 8. 精度

- `analysis.json` / `data.json` 的拉力字段是**小数**：`0.0191` 表示 `1.91pp`，不是 `0.0191pp`；字段单位见 `analysis.json.units`；
- 报告 / analysis.json：拉力、价格拉力、成本拉力、毛利率变化、成本率变化用 pp；收入增长、收入占比、毛利率水平用 %；
- HTML 工作台：按页面约定统一显示 %，不显示 pp；
- 页面：2 位小数，便于阅读；
- 导出主明细 / 维度表 / 订单表：6 位小数，避免小值被四舍五入成 0；
- 复核底稿：全精度；
- 导出主明细的拉力由“价格 + 成本”反推，并用最大余数法对齐合计，保证逐行恒等、上期合计 0、本期合计 ( \Delta R )。

## 9. 报告边界

可以回答：

- 哪个对象、哪张订单、哪一项拉力差了多少；
- 价格 / 成本各贡献多少；
- 象限浓度怎么变、主要由哪些路径带来。

不能回答：

- 客户为什么降价 / 降本；
- 业务动作是否合理；
- 没有数据支撑的原因。
